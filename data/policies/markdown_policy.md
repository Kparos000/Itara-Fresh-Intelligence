# Markdown Policy

## Purpose

This policy defines when Itara Fresh should reduce prices to avoid spoilage losses.

## Core Rules

1. Markdown decisions should consider shelf life, demand forecast, current inventory, margin, and spoilage cost.
2. Markdown should be recommended before disposal when the product still has sellable life.
3. Markdown should not be applied when expected margin loss exceeds avoided spoilage loss.
4. Markdown sensitivity varies by store persona and category.
5. Markdown recommendations must be traceable.

## Required Inputs

- store ID
- SKU ID
- on-hand units
- expiry date
- shelf life remaining
- forecast demand
- retail price
- unit cost
- gross margin
- store markdown response index
- expected sell-through lift
- expected spoilage loss

## Approved Actions

- no markdown
- low markdown
- moderate markdown
- aggressive markdown
- human escalation

## Decision Notes

Markdown decisions should be more aggressive for short shelf-life categories such as prepared foods, seafood, bakery, and meat.

High-income stores may respond differently from price-sensitive stores. The system must use store persona and markdown response index rather than assuming one markdown rule fits all stores.
